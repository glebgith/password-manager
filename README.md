## 📝 Описание
Приложение для безопасного хранения паролей. Все данные шифруются алгоритмом AES-GCM. Доступ разграничен по ролям (Пользователь / Администратор). Включает выгрузку отчетов в Excel и PDF, а также резервное копирование базы данных.

## 🛠 Стек технологий
* **Язык:** Python 3.11+
* **Интерфейс:** PyQt6 (написано вручную, без конструкторов)
* **База данных:** SQLite (5 связанных таблиц)
* **Шифрование:** AES-GCM
* **Отчеты:** openpyxl (Excel), reportlab (PDF)

## ✨ Основной функционал
* Вход по логину и паролю (роли: `admin` и `user`).
* CRUD операции с паролями (добавление, просмотр, копирование в буфер, удаление с подтверждением).
* Генератор случайных надежных паролей.
* Сквозной поиск по названию и логину.
* Выгрузка данных в Excel и PDF.
* Резервное копирование БД.
* Анимации: плавное изменение цвета кнопок, движущийся фон, появление элементов.
